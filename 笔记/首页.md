# 笔记首页

> 最后更新：2026-11-26

## 分区

- [每日](每日/) —— 按日期记，文件名用 `YYYY-MM-DD.md`
- [学习](学习/) —— 专业课、Python、竞赛备赛
- [生活](生活/) —— 日常、健康、行程、穿搭
- [模板](模板/) —— 新建笔记时复制对应模板
- [附件](附件/) —— 笔记里引用的图片等

## 写作约定

1. 一篇笔记只写一个主题，标题写成一级标题。
2. 每日笔记直接复制 `模板\每日笔记模板.md`，改文件名即可。
3. 贴图放 `附件\`，正文用相对路径引用，例如 `![](../附件/示例.png)`。
4. 需要跳转其他笔记时用相对路径链接，保证在任意 Markdown 编辑器里都能点开。
