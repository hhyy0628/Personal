## 今天做了什么

## 学到的东西

- pip 的用户级配置在 `%APPDATA%\pip\pip.ini`，写一次对该用户下所有 Python 生效
- `cache-dir` 可以改，把包缓存从空间紧张的 C 盘挪到其他盘
- 本机 Git 装在 `F:\Git`，之前不在 PATH 里，所以命令行敲 `git` 会提示找不到
