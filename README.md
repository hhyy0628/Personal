# 个人仓库与笔记

- 位置：`F:\Personal`
- 建立：2026-11-26
- 版本管理：Git（本机 Git 装在 `F:\Git`，此处为仓库根目录）

## 目录地图

| 目录 | 用途 |
| --- | --- |
| `笔记\` | Markdown 笔记库，入口是 `笔记\首页.md` |
| `项目\python\` | Python 练习与小工具 |
| `项目\课程作业\` | 课程作业与实验 |
| `项目\竞赛\` | 竞赛、国赛备赛资料 |
| `脚本\` | 一次性脚本、批处理 |
| `素材\` | 图片、参考资料等 |

## 常用命令

```powershell
cd F:\Personal
git status
git add -A
git commit -m "这次改了什么"
git log --oneline -5
```

## 规矩

1. 笔记只写 Markdown，不混 Office 文件到 `笔记\` 里（需要时放 `素材\`）。
2. 提交前先 `git status` 看一眼，别把大文件、密钥、`.venv` 提进去。
3. 一个主题一个文件，文件名说人话，别用 `新建文档1`。
